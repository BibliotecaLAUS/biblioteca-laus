# Biblioteca LAUS

Prototipo de la interfaz pública de la Biblioteca LAUS.

## Estado
Primera versión funcional: catálogo responsive, búsqueda, filtros, enlaces al material y visor modal de preview.

Los datos de prueba están en `catalogo.json`. En la siguiente etapa ese archivo se generará automáticamente desde el Catálogo Maestro de Google Sheets.

## Estructura
- `index.html`: interfaz
- `styles.css`: diseño responsive
- `app.js`: búsqueda, filtros y modal
- `catalogo.json`: datos públicos del catálogo
